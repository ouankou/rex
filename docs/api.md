# API Reference

The API reference is generated by MrDocs and published at:

- [reference](/reference/)

Generate it locally with:

```bash
# Writes docs/reference by default.
bash scripts/generate-api-documentation
```

To keep generated reference output under the build tree:

```bash
MRDOCS_OUTPUT_DIR=build/docs-scratch/docs/reference \
  bash scripts/generate-api-documentation
```

Or build the full docs site (API reference + MkDocs) with:

```bash
# Keeps all docs output under build/docs-scratch.
DOCS_SCRATCH_DIR=build/docs-scratch bash scripts/build-docs
```

Default (writes `docs/reference` and `_site`):

```bash
bash scripts/build-docs
```
