## Reading a declaration

- **Synopsis** shows the signature, with links to referenced types.
- **Declared in** links to the source revision used for this build. Generated headers are identified separately.
- **Members** and **base classes** connect class interfaces; **All overloads** returns to a function's overload group.
- Private members are included for compiler development, not as a promise of a stable public interface.

Generated pages preserve available source comments. An undocumented declaration has no additional contract implied by this guide.
