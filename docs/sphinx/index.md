# REX Documentation

REX is the modernization of the ROSE compiler infrastructure with a Clang/LLVM 20
frontend, focused on source-to-source analysis and transformation. This site is built
with Sphinx, Breathe, and Exhale on top of Doxygen to provide a modern, searchable
documentation experience.
