Namespace IntegerOps
====================


.. contents:: Contents
   :local:
   :backlinks: none




Detailed Description
--------------------

Bit-wise operations on integers.

Many of these are function templates for the best optimization, but we also provide non-template versions for those cases when the arguments are not known at compile time. The non-template versions typically have "2" appended to their names to indicate that they should be the second choiceused only when the template version cannot be used.
